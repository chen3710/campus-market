校园二手交易平台（个人项目）

项目时间：2026.09
技术栈：Spring Boot 3.3.7 + MyBatis-Plus 3.5.7 + MySQL 8.0 + JWT + Lombok + 原生 HTML/CSS/JS
项目地址：https://gitee.com/你的账号/campus-market.git

项目描述：
基于 Spring Boot 开发的校园二手交易平台，后端提供 RESTful 接口，搭配原生 HTML/CSS/JS
前端页面，实现商品发布、订单交易、收藏留言、信用分结算、后台管理等核心功能，支持多
用户在线交易，并针对并发下单场景做了防超卖处理。

个人职责：
1. 负责后端整体架构设计：采用标准三层架构（Controller / Service / Mapper），基于
   MyBatis-Plus 实现数据库交互与分页查询，统一响应体与全局异常处理，错误码语义化
   （400 参数校验 / 401 未登录 / 403 越权 / 404 资源不存在 / 409 状态冲突 / 422 业务规则拦截）
2. 实现用户模块：完成注册、登录、资料管理、信用分流水等接口，密码采用 BCrypt 加密
   存储；基于 JWT + 拦截器 + 自定义注解（@LoginRequired / @AdminOnly）实现无状态鉴权，
   取代 URL 白名单配置，并用 ThreadLocal 传递登录上下文、在请求结束时强制清理
3. 核心交易链路开发：基于带版本号的条件更新（CAS）把「判断在售」与「锁定商品」压成
   一条 SQL，解决并发下单超卖；用「枚举 + 状态流转表」实现订单状态机，非法流转集中拦截
4. 数据库设计与查询优化：设计用户、商品、订单、收藏、留言等 8 张核心表；通过 LEFT JOIN
   与批量 IN 查询消除 N+1，列表接口 SQL 数量恒定不随记录数增长；排序参数走白名单枚举，
   规避 ORDER BY 注入
5. 订单超时自动取消：基于 @Scheduled + fixedDelay 实现定时清理，解决「卖家迟迟不确认
   导致商品被僵尸订单永久锁死」；用 CAS 处理定时任务与用户操作的并发竞争，并把事务方法
   抽为独立 Bean，规避同类内调用绕过 @Transactional 代理而静默失效的坑

项目成果：
1. 实现完整交易闭环（发布 → 下单锁定 → 卖家确认 → 买家完成 → 信用分结算），10 线程
   并发下单同一商品时恰好 1 个成功、其余返回冲突，防超卖逻辑经真实压测验证
2. 建立四层验证体系：53 项 JVM 内自动化测试（25 项单元测试覆盖订单状态机完整流转矩阵
   + 28 项 MockMvc 集成测试覆盖鉴权与状态码语义）+ 108 项真实 HTTP 冒烟断言 + 无头浏览器
   前端渲染验证
3. 项目配套完整 README（含系统架构图、下单链路时序图、数据库 ER 图），并内置 H2 内存库
   模式，无需安装 MySQL 即可一键运行

【四】一句话项目简介（面试开场 / 自我介绍）
────────────────────────────────────────────────────────────────────

我独立做了一个校园二手交易平台，后端 Spring Boot + MyBatis-Plus + MySQL，前端用原生
HTML/CSS/JS。技术上比较有含金量的是三块：一是并发下单用 CAS 条件更新防止超卖，10 个
并发请求只有 1 个能成功；二是用「枚举 + 状态流转表」实现订单状态机，把非法流转收敛到
一处拦截；三是写了 53 项自动化测试加 108 项接口断言来验证这些逻辑，全部可复现。

【五】填写前必读（4 条）
────────────────────────────────────────────────────────────────────

1. 项目时间：上面写的 2026.09 改成你真实的开发周期。实际只有几天不必硬撑成三个月 ——
   面试官会追问每个阶段做了什么，答不上来反而减分。一个人几天做完一个完整可运行项目，
   本身就是能力证明。

2. 项目地址：推送前先把 git 提交身份改成真实姓名和邮箱（当前是占位
   campus-market <dev@example.com>），否则提交记录一看就是模板生成。

3. 技术栈不要加 Docker / Redis / 消息队列 / Elasticsearch —— 项目里没有，一追问就露馅。
   只写 pom.xml 里真实存在的依赖。

4. 个人职责只写真做过的。上面 5 条分别对应 ProductMapper（CAS）、OrderStatus（状态机）、
   JwtInterceptor（鉴权）、ProductMapper.xml（JOIN 消 N+1）、OrderTimeoutScheduler（定时
   任务），面试官让你打开代码你能当场指出来。
